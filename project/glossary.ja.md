# CraftVia 用語集

> 状態：公開前v1文書セットの公式用語です。ハードウェアに関する記述は試験証拠が公開されるまで未検証です。[英語版](glossary.md)を正本とします。

| 用語 | 定義 |
| --- | --- |
| **Core** | MCUと、宣言された動作構成に必要な回路を含む小型MCU回路。 |
| **Core-S** | Core-S仕様で定義するCraftViaの小型Core形状・インターフェース。`S`は物理プラットフォームを表し、固定されたMCU機能マップではない。 |
| **Core実装** | Core-Sインターフェースを特定のMCUと回路で実現する製品。例：Core-S G031。 |
| **Station** | Coreを搭載し、書き込み、デバッグ、給電、通信、ブレイクアウト、操作、計測などを提供する開発設備。 |
| **Station-S** | Core-S物理プラットフォーム用のStation。 |
| **DEV/DUT** | 開発対象または試験対象のCoreに使用するStationのソケットと回路。DUTはDevice Under Test。 |
| **CTRL Core** | 計測やUIなどStation機能の制御に使用するCore。DEV/DUT Coreとは別系統。 |
| **Carrier** | Coreを搭載する用途固有の基板、配線、治具または最終機器。 |
| **MakerCard** | MCU実装とブレイクアウト・試作領域をカード形状へ統合したCraftViaのReference形式。 |
| **物理端子ID** | `N1`、`E4`、`K-SW`など位置を表す識別子。共通の周辺機能を意味しない。 |
| **信号接点** | `N1-N8`、`E1-E8`、`S1-S8`、`W1-W8`の32接点。 |
| **Key接点** | 向きと共通電源に使用する`K-NW`、`K-NE`、`K-SW`の非対称な3接点。`K-SE`は存在しない。 |
| **システム端子** | 宣言された実装プロファイルで書き込み、デバッグ、RESET、BOOT等に予約する端子。 |
| **実装プロファイル** | 特定Core実装が公開する端子割り当てと運用条件。 |
| **DNP** | Do Not Populate。フットプリントはあるが、そのRevisionの正本BOMでは意図的に未実装。 |
| **Version (`v`)** | 製品または互換性の世代。インターフェース、外形、主要動作の非互換変更で上げる。 |
| **Revision (`Rev`)** | 同じ製品Version内のPCB設計改訂。 |
| **Frozen** | 発注またはRelease用の設計・製造成果物が固定済みである状態。検証済みとは限らない。 |
| **Unverified** | 必要な実機試験でまだ確認されていない状態。 |
| **Verified** | 特定した実機、Revision、手順、証拠に基づき確認済みの状態。 |
| **Canonical／正本** | 文書または成果物の内容管理上の優先版。個別注記がなければ英語Markdownを正本とする。 |
| **Reference export** | 回路図PDFや組立PDFなど人が確認するための出力。編集可能ソース、BOM、Gerber正本を置き換えない。 |

## 規定表現

- **MUST / MUST NOT**：必須要件
- **SHOULD / SHOULD NOT**：採用しない場合に理由の記録が必要な推奨
- **MAY**：許容される選択肢
